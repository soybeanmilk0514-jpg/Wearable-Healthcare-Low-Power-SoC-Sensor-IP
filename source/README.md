# Source Code Scope

This project did not include an executable hardware or software implementation.

## No Source Code Is Published Because the Submitted Project Did Not Contain

- RTL source
- SPICE / Spectre netlists
- TCAD decks
- firmware
- sensor-control software
- PCB design files

## Main Technical Artifact

The artifact is the **development-oriented technology map** connecting:

```text
Product requirement
   ↓
SoC architecture
   ↓
Sensor IP
   ↓
Low-power circuit / device strategy
   ↓
Process / materials / packaging
```

The repository therefore documents the technical relationships rather than inventing implementation code that was not part of the original project.
