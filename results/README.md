# Results / Structured Analysis Tables

This project did not generate experimental or simulation result datasets.

The CSV files in this directory are **structured summaries reconstructed from the submitted report**.

## Files

- `low_power_strategy_matrix.csv`
  - low-power mechanisms by engineering level
- `sensor_ip_matrix.csv`
  - sensor / interface blocks and key design concerns
- `company_comparison.csv`
  - company examples exactly in the framing used by the project report

These tables are portfolio organization artifacts, not measured data.
